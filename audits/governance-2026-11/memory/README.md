# The agent's memory files deleted by #229

The twelve files of the agent's private memory (outside the
repository) that #229 deleted when it brought the memory under C183,
where a rule lives. They are here as they were, with only the
harness's session ids taken out of their headers, so that git keeps
what they said. The close of #229 (`git log --grep='^Step: process-229'`)
says where each rule they held went: a line in the tree, a check that
already holds it, or dropped with its reason. The commit after this
one deletes the directory; cite a file as
`audits/governance-2026-11/memory/<file>` at this commit.
