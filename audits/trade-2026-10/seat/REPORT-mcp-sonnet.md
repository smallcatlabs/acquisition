## 3. Faults
Worst first. "Person" = a human driving the same server would meet it too; "agent" = only an agent.

1. **A count's `resolved` list looks like the answer's breakdown but is over the whole store** (calls 19, 20). 3. **Silent unfetched coverage, unexplained**: scope says `never_fetched: 2940`, `fetched: 546`, oldest fetch 1788810111 and newest 1792074048 (call 4) but not what a never-fetched thing is (tabs? items?) nor that such tabs' items cannot appear in any answer. A "no, you have none" answer (call 10 zero) cannot be trusted on this basis. It gave me no way to say "your answer excludes N tabs". Both; I could not resolve it from the tool.
4. **Very large answers for plain asks**: three rows cost ~13 KB (call 7); a 22-row ring list ~30 KB (call 6), which my harness cut and I had to repeat as call 7; each count bucket repeats the full query text in its `request` (call 8: 13,693 bytes for 17 numbers; call 15: 9,787).
