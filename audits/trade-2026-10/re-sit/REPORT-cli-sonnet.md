## 1. Before touching anything

**From the brief:** acq is the command line of Acquisition, a PoE inventory tool; it fetches stashes/characters via a local daemon into a store on this machine; one account GERWARIC; no login, no daemon in this world; API is a mock; writing/pricing is safe here (the brief).

**From the tour (TOUR.md):** it can list profile/leagues/characters/stashes, fetch tabs (`refresh`, `stash`), submit jobs, manage sync policy and refresh plans, set/clear prices and render a shop forum page (`price`, `shop render`), and search the local store, including by pasted trade-site URL (`search --trade`), with `--count`/`--cross`, `show <id>`, `tabs`, `store ...`. Needs: OAuth login (`acq auth`) and a daemon (lazy-spawned) for job verbs that hit the API (profile, leagues, characters, stashes, stash, refresh, submit); the network via that daemon. Offline, no daemon: pricing, shop, tabs, store, search, show, policy compile, accounts. Would not run without asking the person: `auth`/`logout`, `refresh --apply`/`--all`/`--deep`, `submit`, `cancel`, `policy set`, `price set/clear`, `store import/rebuild`, `daemon stop/reset-tripwire` — they spend rate limit, change the store/policy/prices or the person's session. The tour also mentions files I may not read (CLI-REFERENCE.md, AGENTS.md, etc.) and a build step, which are not usable here.

T0, after looking (calls 1-4): `acq --help` (call 1) confirms the tour's verb list. Store as found: Standard, 3347 tabs of which 405 fetched, 2926 never fetched, 16 folders, 20231 items (call 3); store file total 22721 items (+6 removed), 3444 tabs across every realm/league, 65 characters, league list never fetched, 4 refused bodies (call 4). Tabs last fetched "40d ago" (call 3). So the store is old (40 days) and 88% of tabs were never fetched — a search sees only fetched ones.

## 3. Faults

1. (Agent and person) Searches report the answer "from fetched tabs only" while 2940 of 3486 locations were never fetched (MapStash 2489/2582, UniqueStash 437/521, calls 5, 12, 20-21). The notice is printed every time (good) but T7 shows the cost: "0 matches" on Loreweave tells me nothing about where it is, and no command tells me which unique tab to fetch or how (call 22 plan skipped them). A person would hit this too.
2. (Both) `--sort` on a "sum(...)" ranks by explicit+implicit while the filter uses explicit only, with no note (call 15: Dire Torc 41 explicit/57 total above Empyrean Gyre 51/51). "Best first" is therefore not the site's order, and the tool says the site sort is "reported, never applied" for trade searches.
3. (Agent mostly) `--trade` page size is 20 and the `--next` token is a 1.5 KB string I had to paste whole (call 7); `--limit` is accepted beside a URL (calls 8, 16, 17) but `--count` beside `--trade` gave a count table without rows (call 16), which is fine but was only found by trying.
4. (Both) "ambiguous" does not say whether the ambiguity changed this answer (calls 8, 12, 13, 16, 17); I had to run --explain and extra searches to find out (calls 9-11).
5. (Both) The term table reads "counted over all live pc items in all leagues" and so shows e.g. 30 for magic find where the answer is 27 (calls 14-15), a different number next to the total.
6. (Agent) `seat.py report` printed "REPORT.md is N bytes" with no word of success; I could not tell it had appended. Door, not tool.
7. (Both) `price list` default output is 14 KB over all listed items, grouped by container, with no filter by a search result (call 29).

## 4. What the tour and the help did not say

- That the field names for a typeline/base/name are `typeline~`, `base~`, `name~` with `~` as a substring operator: expected in `search --help`; learned by trying in call 17 (translated query printed) and calls 20-21.
- That the translated trade query can be re-run edited (drop a clause) by copying the printed `query` line: not stated; call 6 worked.
- That a trade URL's page 2 needs `--next` with the token copied whole (printed in `more`, call 5; used in call 7). The help does say it.
- That map tier is a field `map_tier` and `--count` takes it (call 18); not in the tour.
- That unfetched tabs cannot be reached offline and `refresh --plan` skips them (call 22).
- That items in "(Remove-only)" tabs are not public: the tour says "GGG's mark on a tab whose items can only be taken out" (call 3), and `price list` says "(not public)" (call 29); the link to "a buyer cannot see it" I made myself.
