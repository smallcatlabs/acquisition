## 1. Before touching anything

**What the brief told me (the brief):** `acq` is the CLI of Acquisition, a Path of Exile inventory tool; the store holds `GERWARIC` (a copy of a real ~50 MB collection with prices, no session) and a second account I log in through the door; the API is a mock; there is no keyring; the door's daemon idles out after 30 minutes, the shipped default is one minute.

**What the README told me:**
- Can do: download stash tabs and characters through a daemon (`acqd`) that obeys GGG's rate limits; search them offline with a query language; set prices; render forum shop pages to paste; keep a league fresh with a policy → plan → apply cycle; an MCP server (`acq-mcp`) with 25 tools mirrors the CLI.
- Needs: a login (browser, `acq auth`) and a daemon for every "job" verb (`profile`, `leagues`, `characters`, `character`, `stashes`, `stash`, `refresh`, `submit`); `auth`, `jobs`, `status`, `cancel`, `daemon` talk to the daemon. The store, search, pricing and shop verbs need no daemon and no network. Without a keyring "a login lasts as long as the daemon that holds it" and `acq daemon stop` "logs you out".
- Before a first command: section "Before the first command" — the rate limit is the clock (a first sync of a few hundred tabs takes most of an hour), what needs the daemon, Standard is the default league for `stashes`, `stash`, `refresh --plan`, `tabs`, `price status`, `shop render`; where the data and logs are. Install: keep the three binaries together, put them on `PATH`, on macOS clear quarantine if browser-downloaded.
- Would not run without asking: `acq daemon stop` (logs the person out without a keyring and cancels nothing obvious), `acq policy set` (README "Known gaps": replaces the whole policy, every realm), `acq refresh --all` / `--apply` (hour-long request bursts against GGG's limits), `acq store import` / `store rebuild` (rewrites the store), `acq auth logout`, `acq daemon reset-tripwire`, and any `price set`/`price clear` on the person's real store. The README points at `AGENTS.md`, `CLI-REFERENCE.md`, `CONTEXT.md`, `decisions/*.md`, `SECURITY.md`, `CONTRIBUTING.md` and source files in the Knobs table; none is in the archive ("Every other file this page names is in the repository") and I may not open them.
