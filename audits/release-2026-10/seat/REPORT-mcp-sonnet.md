**What the brief gave me (the brief):** the tool is acq-mcp, the MCP server of Acquisition for Path of Exile; one account, GERWARIC, is in the store, a copy of a real collection of about 50 MB with the person's prices; no login and no daemon exist in this world; every call goes to a mock of the game API (the brief).

**From the README alone (before any call):**
- Can do: download stash tabs and characters to the machine, search them offline, price items, render forum shop pages for pasting, keep a league fresh through a plan (`refresh_plan`/`apply_plan`), run jobs (`submit_job`). It says the MCP tools are `search`, `describe`, `show`, `tabs`, `price_status`, `price_set`, `shop_render` "and four more"; it does not list them and points to `MCP-REFERENCE.md`, which I could not follow here.

- Not clear from the README: how to start the server for an agent beyond the one-line config. The README says it uses `~/Library/Application Support/...` for the store, and does not say how `acq-mcp` is told a different store or account.

**What `open` told me (call 1):** the instructions say the provider is mock.
